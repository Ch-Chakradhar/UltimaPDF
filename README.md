# UltimaPDF

The only PDF Reader that you will ever need. Built with the `androidx/pdf` library and Jetpack Compose (to get the best performance on Android), sticking to modern best practices for the most part.

No ads, fully open source.

> [!WARNING]
> *androidx/pdf* is still in Beta and *1.0.0-beta01* was used to create this. The API might change and be incompatible with newer versions unless updated.

This project was initially built only for myself, but I thought this might be useful for others too.

Please star ⭐ this repo to show your love.

Feel free to post about any bugs you find in this app or any feature requests ~~(can't guarantee to implement them)~~.

> [!NOTE]
> This is only a Reader, so don't expect any editing features anytime soon.
